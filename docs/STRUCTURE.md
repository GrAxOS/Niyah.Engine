# Structure Best Practices

- chunks/ -> كل chunk ملف منفصل 4 خانات
- evidence/ -> أدلة خام raw قبل التنظيف
- nodes/ -> تعريفات الـ nodes المجمعة (اختياري للتصفح)
- edges/ -> تعريفات الـ edges المجمعة
- schema/ -> JSON Schema للتحقق
- manifests/ -> سجل الـ chunks + checksum
- audits/ -> سجلات الجودة
- scripts/ -> سكربتات البناء والتحقق
